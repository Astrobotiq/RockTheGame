Bulunan web kaynakları (dosya indirilmedi)

  • Kenney Pattern Pack Extra (CC0) - CC0. Halftone olduğu doğrulanmadı; 80+ PNG/SVG desen. Referansa uzak (büyük olasılıkla tek renk desenler).
  • Graphics Fuel - 16 Free Halftone Seamless Patterns - 998x998, tileable, .PAT+.PNG, siyah-beyaz nokta rampaları. Ticari kullanım ücretli sürümde olabilir; lisans sayfada açık değil. Referansa orta-uzak (tek renk).
  • Free Halftone Dot + Grain Texture (Gumroad, mikeliszarins) - Lisans doğrulanmadı. Overlay dokusu, tek renk.
  • Risograph Textures (itch.io, aosmiles) - Ücretli (min. 5 USD), lisans sayfada kontrol edilmeli. Taranmış riso doku, riso_grain için kıyas.
  • InstantGradient / paper-design shaders - Apache-2.0 (ticari, atıf gerekmez; LICENSE/NOTICE korunmalı). Web shader'ları; CMYK halftone referansı olarak okunabilir.
  • daniel-ilett/shaders-halftone - MIT. Unity URP + Shader Graph halftone (diffuse ışığa bağlı nokta). CMYK yok.
  • Godot Shaders - CMYK Halftone (OskarGosbol) - MIT (kod). Kanal başına açı, ofset (kayık baskı), süpersample AA. Teknik referans.
  • Shadertoy 4dSSRG - Fetch 403; Shadertoy varsayılanı CC BY-NC-SA 3.0 (ticari DEĞİL). Yalnız teknik okuma, kod kopyalama.
