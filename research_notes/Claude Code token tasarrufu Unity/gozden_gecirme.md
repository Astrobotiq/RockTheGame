## 1. Duzeltmeler (notlar arasi celiskiler ve yanlislar)

1. **CLAUDE.md boyutu (en onemli duzeltme).** `claude_code_yerlesik.md` "CLAUDE.md 200 satirin cok ustunde" diyor; `yerel_proje_denetimi.md` "71 satir" diyor. Olcum (`wc`): **117 satir, 13,584 B**. Yani 200 satirlik resmi hedefin ALTINDA; ikisi de yanlis (13,584 B dogru). Dokuman: "target under 200 lines per CLAUDE.md" (memory sayfasi, dogrulandi). CLAUDE.md'yi "sisman" diye cerceveleyen her oneri (yerlesik Sec.3 cikarimi, denetim Sec.1 "1.5-2.5k token/oturum") abartili: toplam sabit yuk ~3.5-4k token, kazanc en fazla ~1.5-2k token/istek ve cache-read fiyatinda kucuk.
2. **Glob .gitignore'a uymaz.** Denetim Sec.3: "Grep/Glob bunu (ripgrep) uyguladigi icin Library/Logs/obj atlanir". Tools-reference (dogrulandi): "Glob doesn't respect .gitignore by default ... differs from Grep, which skips gitignored files"; Glob icin `CLAUDE_CODE_GLOB_NO_IGNORE=false` gerekir. Grep gitignore'a uyar (dogrulandi, `Grep respects .gitignore`). `unity_ozel.md` ve `claude_code_yerlesik.md` bunu "dogrulanmadi" diye birakmisti; cevap artik belli: **Grep evet, Glob hayir (varsayilan)**. Pratik sonuc: `Glob **/*` Library'nin 46k dosyasini listeleyebilir; Read deny (Library/**) Glob listesinden de adlari gizler (permissions: "Directory listings omit names matched by a Read deny"), yani Read deny Glob icin gercekten isler; Grep zaten korunuyor.
3. **MCP semasi: celiski.** `unity_ozel.md` Takeaway "MCP maliyeti her zaman bagliamdaki arac listesi (4k-30k)" diyor; `claude_code_yerlesik.md` ve `graphify` notu "tool search ile ertelenir, sadece adlar" diyor. Costs sayfasi (dogrulandi) ertelemeyi onayliyor. unity_ozel'in 27k rakamlari esik ustu/eski davranis; bu projede MCP zaten kullanilmiyor (`.mcp.json` yok, CLI + eval), yani konu buyuk olcude alakasiz.
4. **Skill/plugin yuku 7-10k token: olculmemis tahmin, ustelik ust sinirli.** Skills dokumani (dogrulandi): liste butcesi "1% of the model's context window" ile sinirli, aciklama basina 1,536 karakter tavan; `/context` Skills satiri butce SONRASI boyutu gosterir; `/doctor` maliyet tahmini, `/skill-doctor` kullanilmayan skill'leri bulur. Denetimin ~110 skill x 35-60 token = 4-7k hesabi (a) bu masaustu oturumundan sayilmis (CLI'dan degil; denetim kendisi de bunu soyluyor), (b) butceyle kirpilabilir. CLI'da gercek: ~64 skill. "7-10k" bir ust bant tahmini, gercek deger `/context` ile olculmeli.
5. **Skill/plugin kapatma mekanigi notlarda eksik/yanlis.** Denetim "plugin bazli aciliyor, ~20 skill'i kapatmak mumkun degilse..." diyor. Dokuman: `skillOverrides` (on / name-only / user-invocable-only / off) **plugin skill'lerine uygulanmaz**; plugin skill'leri `/plugin` ile (plugin kapat/kaldir) yonetilir. Kullanici (`~/.claude/skills`) skill'leri icin `skillOverrides: "off"` veya `"name-only"` calisir; frontmatter `disable-model-invocation: true` listeden cikarir. Yani: supabase/vercel/web-design kullanici skill'leri `skillOverrides` ile kapanir; unity plugin'inin 31 skill'i ya hep ya hic.
6. **Subagent maliyeti.** Notlar tutarli (is akisi: "tasarruf baglam izolasyonu, token degil"; yerlesik: "toplam token artar"), ama is_akisi/yerlesik'teki 4x/15x rakamlari Anthropic'in arastirma sisteminden, Claude Code subagent'larindan degil; notlar bunu zaten isaretliyor, fakat "Haiku log triage" onerisi bu rakamlarla degil kendi mantigiyla degerlendirilmeli (bkz. tablo).
7. **Cache TTL.** Celiski yok; tek nokta: yerlesik not 1h TTL'i "abonelikte varsayilan" diyor (docs, dogrulanmadi bu turda ayri). Kullanici modeli `opus` (dogrulandi: `~/.claude/settings.json` `"model": "opus"`); abone mi API mi bilinmiyor, TTL onerilerinin degeri buna bagli.
8. **.claudeignore vs Read deny.** Celiski yok; dokuman metni dogrulandi: ".claudeignore ... has no effect, so move its entries into Read deny rules". Eksik: Read deny "best-effort" Grep/Glob icin; Bash/PowerShell `cat`/`Get-Content` ayri (PowerShell icin ayri `PowerShell(...)` deny kurallari var). Yani Read deny gizli dosyalara kesin kilit degil, kaza onleyici.
9. **Graphify.** ~146k yildiz dogrulandi (145.9k, org Graphify-Labs). "71.5x" README'de YOK (sadece Graphify Cloud icin "80%"); not bunu zaten pazarlama diye isaretliyor, dogru. Claude hook'u README'ye gore Read/Glob/Bash-okuyucular (`cat`, `head`, `sed -n`) icin de tetikleniyor, strict modda yalniz Read+Grep ortak tek ret; nottaki "Bash ve Glob sadece tavsiye" ifadesi README ile uyumlu. C#/.unity destegi README'de adlandirilmiyor ("~40 dil"); not `docs.graphify.com` supported-inputs'a dayaniyor, ben acmadim: **dogrulanmadi**. Bagimsiz benchmark (7.3x, build ~240k token, Windows `--update` hatalari) tek bir ikincil blog; ben ilk elden dogrulamadim.
10. **RTK/PowerShell.** Issue #2115 acik ve atanmamis (dogrulandi); PowerShell kismi issue'nun yan notu, kok konu eski Windows dokumani; baska bir issue (#1319) durumu gorulemedi; bir maintainer "PR acik" demis ama PowerShell'i kapsadigi belirsiz. Yani "RTK PowerShell tool icin tetiklenmez" **kismen dogrulandi, guncel durum belirsiz**. "Net tasarruf ~0" iddiasi Wavect'in ozetledigi 3 calismaya dayaniyor (+7.6 / -4.8 ns / -3 vs +7), ilk elden dogrulanmadi.
11. **Denetim Sec.2: "Stop hook zaten token-ucuz" — DOGRU, ben de gordum.** `check-compile.sh` parmak izi ayniysa sessizce `exit 0`, Editor yoksa tek satir, hatada 15 satir. settings.json ve hook dosyasi okundu. TASKS.md satir sayisi 85 yazilmis, ben 93 olcdum (calisma agaci o arada degismis; onemsiz).
12. Denetim Sec.3 "9.4 MB sahne Read ile acilirsa 2.4M token" abartili: Read araci 25k token ustunu reddeder (yerlesik notta `CLAUDE_CODE_FILE_READ_MAX_OUTPUT_TOKENS`). ## 3. Projeye zarar verebilecek oneriler

1. **`Read(**/*.asset)` veya genis `*.prefab` deny'i.** Edit araci once Read ister; Read deny'li dosyaya Edit de calismaz. `PlayerStatsSO` vb. `.asset` dosyalari CLAUDE.md kural 4 geregi ayarlanir; blanket `*.asset` deny'i bunu kirar. Sadece `**/*SDF.asset` (TMP atlaslari) ve `Assets/Plugins/**` gibi dar kalip guvenli. Prefab: CLAUDE.md zaten "eval kullan" diyor, `.unity` icin Edit/Write deny'i var; `Read(**/*.unity)` tutarli. `*.prefab` icin 43 MB / 90 dosya, ama kucuk prefab'lar (HUD, pause) bazen dogrudan incelenebilir; en azindan >1 MB olanlar adlandirilarak engellenebilir (RoomNew-*  Variant).
2. **`Read(**/*.meta)`:** GUID gerektiginde (script/prefab referansi arama) engel olur; kazanc kucuk (2.3 MB dagitik). Atla.
3. **`Read(docs/ui-research/*.html)`, `Read(docs/moodboard/**)`**: kullanicinin aktif UI arastirmasi/moodboard'u; UI is yapilirken lazim olabilir. Deny yerine `docs/archive/` ve CLAUDE.md'de tek satir uyari; ya da deny yalniz `dashboard.html` (eski, kok) ve `Assets/_Recovery/**`.
4. **Hook ile cikti kirpma (PreToolUse `| tail -100`)**: hata mesajinin basi/ortasi kaybolabilir (derleyici hatalari, NUnit stack'ler basta olur). Repo'nun mevcut deseni (yalniz `error CS`, 15 satir, hata yolunda) dogru; test/ unity komut ciktisini genel `tail` ile kirpmak "bilgi gizler" riski tasir. Ancak PowerShell/bash ayrimi da var: hook yalniz Bash matcher'ina baglanirsa PowerShell tool'u kacar.
5. **Graphify strict hook:** ilk Read/Grep'i reddeder; Stop-hook + `unity command` akisini ve CLAUDE.md "kaniti goster" kurallarini bozar. Strict kurulmamali.
6. **SessionStart'i kisitlama:** `deadlines.ps1` cikisi zaten 485 karakter; "Gecikenler" ust siniri cok kucuk kazanc, ayrica planlama kurali (kullaniciya geciken task'lari gostermek) kaybolabilir.
7. **Stop hook parmak izini daraltmak:** `Assets/Plugins`'i disarida birakmak guvenli, ama kok `Packages/` yerel paketi veya yeni bir klasor eklenirse (asmdef yeni yerde) dogrulama atlanir. Kazanc yalniz sure (birkac yuz ms). Risk>kazanc.
8. **Memory/CLAUDE.md dedupe:** CLAUDE.md'deki bir satiri memory'den cikarmak guvenli; tersi (CLAUDE.md'den silip sadece memory'de birakmak) guvensiz: memory otomatik uretilen/duzenlenen, "checked into codebase" degil, takim/yeniden-klon ile kaybolur.
